# Research software

Open research tools for sport and exercise biomechanics, developed by Dr Tommy Bright
([ORCID 0000-0001-8089-817X](https://orcid.org/0000-0001-8089-817X), [ResearchGate](https://www.researchgate.net/profile/Thomas-Bright-4)).

All tools run in the browser. Data are processed locally and never uploaded.

| Tool | Description | Version |
|---|---|---|
| [Force-Time Analysis](https://tommyebright.github.io/research/force-time-analysis/force-time-analysis.html) | Force platform analysis of normal, band-assisted and band-resisted countermovement jumps ([details](force-time-analysis/)) | 1.1.0 |

Each tool has its own folder with a README and a `CITATION.cff`. Please cite the specific tool you use.
